# Дела — менеджер задач в духе Things 3

Веб-приложение (PWA) без сборки и зависимостей: откройте `things/index.html` через любой статический сервер
(например, `python3 -m http.server` в корне репозитория → http://localhost:8000/things/). Данные хранятся в `localStorage`
этого браузера, работает офлайн, ставится на главный экран телефона.

## Возможности

- **Списки:** Входящие, Сегодня (с блоком «Этим вечером»), Предстоящие (по дням на неделю вперёд, затем по месяцам),
  В любое время, Когда-нибудь, Журнал, Корзина.
- **Проекты и области:** прогресс-«пирог», заметки, заголовки внутри проекта (архивировать, превратить в проект),
  крайние сроки, планирование проекта целиком, завершение/отмена, дублирование.
- **Задачи:** заметки, чек-листы (Enter — новый пункт, вставка нескольких строк — несколько пунктов), теги,
  «Когда» с вводом обычным текстом («завтра», «пт», «через 3 дня», «12.11»), крайний срок, повторы
  (по расписанию или после выполнения, дни недели), напоминания с системными уведомлениями.
- **Теги:** вложенные теги, фильтр по тегу в любом списке (учитывает теги проекта и области), отдельный список тега.
- **Перетаскивание:** мышью или долгим нажатием — сортировка, перенос в «Этим вечером», на день в «Предстоящих»,
  на списки и проекты в боковой панели; проекты и области тоже перетаскиваются.
- **Быстрый ввод** (Ctrl/Alt+Пробел) и **быстрый поиск** (`/`, Ctrl+F или просто начните печатать).
- **Клавиатура** как в Things: Ctrl+K выполнить, Ctrl+T сегодня, Ctrl+E вечером, Ctrl+S «Когда», Ctrl+Shift+M переместить,
  Alt+1…7 списки, Ctrl+Z отмена и т. д. Полный список — клавиша `?`.
- **Телефон:** домашний экран со списками, кнопка «+», свайп вправо — «Когда», свайп влево — выбор нескольких.
- Отмена/повтор любого действия, светлая и тёмная темы, экспорт и импорт JSON.

## Устройство

| Файл | Что внутри |
| --- | --- |
| `js/store.js` | модель данных, сохранение, история отмены, выборки для списков |
| `js/dates.js` | даты, разбор текста в дату, расчёт повторов |
| `js/pickers.js` | всплывающие окна: Когда, Срок, Теги, Переместить, Повтор, Напоминание, меню |
| `js/app.js` | маршрутизация, отрисовка списков, редактор задачи, перетаскивание, клавиатура, поиск, настройки |
| `sw.js` | офлайн-кэш |
